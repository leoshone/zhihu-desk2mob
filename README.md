# 知乎桌面版 → 手机宽度适配

在手机浏览器（Kiwi 等）里把**知乎桌面版网页**收进手机宽度显示：字号恢复正常、页面不再需要左右拖动。

脚本文件：**[`zhihu-desk2mob.user.js`](./zhihu-desk2mob.user.js)** · 当前版本 `0.2.0`

---

## 效果

Kiwi 勾选「桌面版网站」后，Chromium 会把 layout viewport 强行撑到 980 CSS px，再把整页缩到约 0.4 倍塞进 393px 的屏幕——正文字号 15px 变成 6px，页面还得横向拖。

脚本用 `zoom` 精确抵消这个缩放：`393 × 2.494 × 0.4 = 393`，净效果 1 CSS px = 1 设备独立 px。

实测（模拟 Pixel 7，屏幕 393px，问题页）：

| 配置 | zoom | 布局宽 | 横向溢出 | 超宽元素 |
|---|---:|---:|---:|---:|
| 不装脚本 | 1 | 980px | 52px | 13 个 |
| 参考脚本 v3.1 | 1 | 980px | 52px | 13 个 |
| **本脚本 0.2.0** | **2.4936** | **393px** | **0** | **0** |

> 参考脚本 v3.1 的四项指标与不装脚本完全一致——不是效果差，是完全没生效。根因是它在 `@run-at document-start` 阶段访问了还是 `null` 的 `document.head`，`appendChild` 抛错导致整个脚本中断。详见[制作与测试记录](./制作与测试记录.md)第 4 节。

顺带修好了一个知乎自己的 bug：不勾桌面版、纯移动模式下，知乎发现页本身就横向溢出 **639px、206 个元素超宽**。装了脚本后归零。

### 两栏布局（专栏页）

专栏页的右侧栏（"关于作者""大家都在搜"）会挤占屏幕，把正文压成窄条。0.2.0 起默认把侧栏移到正文下方：

| 状态 | 主列宽 | 侧栏 |
|---|---:|---|
| 不装脚本 | 636px（被挤）| 占 296px |
| 装脚本 · `sideColumn='bottom'` | **361px** | 移到正文下方 |
| 装脚本 · `sideColumn='hide'` | **361px** | 隐藏 |

识别靠结构启发式——同一行里位置靠左、文本量大的当正文，靠右的当侧栏，**不依赖知乎的类名**，改版不会失效。

## 安装

### Kiwi 浏览器

1. 把 `zhihu-desk2mob.user.js` 拷到手机存储（如 `Download/`）
2. 打开 `kiwi://extensions`，开启右上角「开发者模式」
3. 把 js 文件拖进页面（或让 Kiwi 打开该文件的 `file://` 地址）确认安装

也可以先装 Tampermonkey，再 Import 这个 js。

### 使用

打开 `www.zhihu.com` → 菜单勾选「桌面版网站」→ 刷新。

右上角有状态角标 `✓ 393px ×2.49`，点击可暂停/恢复对比。不想要角标就把脚本顶部 `CONFIG.debug` 改成 `false`。

### 自检

控制台执行：

```js
window.__zhihuFit()
```

健康状态下 `横向溢出` 应为 `0`。

## 可调参数

脚本顶部 `CONFIG`：

| 参数 | 默认 | 说明 |
|---|---|---|
| `debug` | `true` | 右上角状态角标，点击可暂停/恢复 |
| `fitHeader` | `true` | 顶栏超宽时自动裁剪导航项 |
| `hideSidebar` | `true` | 隐藏悬浮按钮、App 下载条 |
| `sideColumn` | `'bottom'` | 右侧栏：`'bottom'` 移到正文下方 / `'hide'` 隐藏 / `'keep'` 不动 |
| `fixVUnits` | `true` | 修正 zoom 下失真的 `vw`/`vh` |
| `bodyFont` | `16` | 正文基准字号（px） |
| `sidePadding` | `12` | 页面左右留白 |

## 它做了什么

1. **抵消缩放** — `html { width: 393px; zoom: 980/393 }`
2. **拆掉硬编码 min-width** — 知乎顶栏 1175px、问题头部 1032px、主列 694px
3. **按实测宽度收拾 emotion 原子 CSS** — 知乎 84 张样式表、7208 条规则几乎全是哈希类名，选择器追不上改版，所以主力是扫描全量 DOM 处理显式 px 宽度、`flex-basis`、`flex-shrink:0`、负 margin
4. **修正 vw/vh** — zoom 下 `100vh` 会放大 2.49 倍，脚本把 `vh`/`vw` 改写成 `calc(N * var(--zf-vh))`
5. **拆两栏布局** — 专栏页等场景下把右侧栏移到正文下方，识别靠结构启发式而非类名

代码块、表格、轮播这类本来就该横向滑动的容器会打上 `data-zskip` 跳过压缩，保留原生手势。

## 已知限制

- **未做真机验证**，全部测试在 Playwright + Chromium 模拟环境完成
- 只测了问题页和发现页两个**真实**页面；个人主页、搜索结果页、评论区未覆盖
- **专栏页是复刻测试页验证的**（真实页面被登录墙 + IP 风控拦截），逻辑已验证，真机观感未验证
- 知乎改版可能导致 `fitHeader()` 和 `hideSidebar` 的部分规则失效（主力扫描逻辑不受影响）

详见[制作与测试记录](./制作与测试记录.md)第 10 节。
