# 知乎桌面版 → 手机宽度适配

在手机浏览器（Kiwi 等）里把**知乎桌面版网页**收进手机宽度显示：字号恢复正常、页面不再需要左右拖动。

脚本文件：**[`zhihu-desk2mob.user.js`](./zhihu-desk2mob.user.js)** · 当前版本 `0.7.0`

> **v0.7.0**：评论弹层关不掉的系统级修复——① 弹层归位：桌面版弹层是「top:50% + translate 居中」，内容超高时上半截（连同关闭按钮）被顶出屏幕，先改成贴顶+限高+内部滚动，关闭按钮永远可见；② 关闭必须复核：老逻辑「点一下关闭按钮就算成功」，按钮点击不被 React 接住时就永远关不掉，现在每一步（点按钮→ESC→兜底隐藏）做完都重新检测，没关掉才走下一步；③ 弹层识别排除纯遮罩（backdrop 与内容层同 z-index 且先插入时，老逻辑会挑中遮罩白忙一场）；④ 返回键兜底加宽松判据（覆盖 85%×50% 且带文字的浮层），常规判据漏掉的评论层也能被返回键关掉，同时无弹层时返回键行为完全不变；⑤ 关弹层后自动解开知乎加的 body 滚动锁。
> **v0.6.1**：修复 v0.6.0 猎手白屏——节点插入瞬间未布局（offsetWidth=0），祖先爬升穿透卡片直到整页容器并藏掉。改为：未布局不判定、命中节点自身须 ≥200px、不向上爬、含富内容的不碰。
> **v0.6.0**：新增"早期侧栏猎手"——document-start 起监控 DOM 插入，右栏（关于作者/推荐阅读等特征）出现的同一帧内隐藏，消除"先显示后隐藏"的闪烁。防误伤：正文富文本容器内不处理。
> **v0.5.1**：修复专栏页右侧栏"跑到底部"——右栏无语义类名（哈希类名 div）时，崩塌修复会把侧栏当内容块撑满整行。现在崩塌修复前先做两栏识别，恰好两个可见块且正文文本量占优时直接隐藏侧栏。
> **v0.5.0**：页面底色刷白（桌面版 body 是 #f6f6f6 灰底，主列收窄后两侧露灰），叠层内边距收敛（外层 6px、内容层 12px），正文可用宽度 329px → 345px。

> **v0.4.1 修复**：v0.4.0 的侧栏 CSS 里有 `[class*="Recommend"]`，而首页信息流每条帖子的类名都带 `TopstoryItem-isRecommend`，导致登录后首页帖子列表整列被 `display:none`（白屏）。已移除该选择器，"推荐/相关"侧栏交给 `hideRightRail()` 的位置判断处理。详见 `测试脚本/test_home_regress.py`（复刻页 A/B 回归）。

## 效果

Kiwi 勾选「桌面版网站」后，Chromium 会把 layout viewport 强行撑到 980 CSS px，再把整页缩到约 0.4 倍塞进 393px 的屏幕——正文字号 15px 变成 6px，页面还得横向拖。

脚本用 `zoom` 精确抵消这个缩放：`393 × 2.494 × 0.4 = 393`，净效果 1 CSS px = 1 设备独立 px。

实测（模拟 Pixel 7，屏幕 393px，问题页）：

| 配置 | zoom | 布局宽 | 横向溢出 | 超宽元素 |
|---|---:|---:|---:|---:|
| 不装脚本 | 1 | 980px | 52px | 13 个 |
| 参考脚本 v3.1 | 1 | 980px | 52px | 13 个 |
| **本脚本 0.4.0** | **2.4936** | **393px** | **0** | **0** |

> 参考脚本 v3.1 的四项指标与不装脚本完全一致——不是效果差，是完全没生效。根因是它在 `@run-at document-start` 阶段访问了还是 `null` 的 `document.head`，`appendChild` 抛错导致整个脚本中断。详见[制作与测试记录](./制作与测试记录.md)第 4 节。

顺带修好了一个知乎自己的 bug：不勾桌面版、纯移动模式下，知乎发现页本身就横向溢出 **639px、206 个元素超宽**。装了脚本后归零。

### 右侧栏（首页 / 问题页 / 专栏页）

右侧栏（"关于作者""大家都在搜""知乎热榜"）会挤占屏幕，把正文压成窄条。**0.4.0 起默认全部去掉**：

| 状态 | 主列宽 | 侧栏 |
|---|---:|---|
| 不装脚本 | 628px（被挤）| 占 300px |
| 装脚本 · `sideColumn='hide'`（默认）| **361px** | 去掉 |
| 装脚本 · `sideColumn='bottom'` | **361px** | 移到正文下方 |

识别是两条腿走路，**都不依赖知乎的类名**：

1. **结构启发式** — 同一行里位置靠左、文本量大的当正文，靠右的当侧栏
2. **从正文反查**（0.4.0 新增）— 先定位文本量最大的内容块，再从它向上爬 5 层检查兄弟元素，四条判据同时成立即判定为侧栏：宽度 ≥ 100px、在正文右侧、垂直与正文重叠、文本量少于正文

第 2 条是必需的：真机实测「侧栏候选（按类名）命中 **0 个**」——现代知乎大量用 emotion 哈希类名，光靠类名盖不全。评论区、底部推荐因为垂直不重叠或文本量不足，不会被误伤。

## 安装

### Kiwi 浏览器

1. 把 `zhihu-desk2mob.user.js` 拷到手机存储（如 `Download/`）
2. 打开 `kiwi://extensions`，开启右上角「开发者模式」
3. 把 js 文件拖进页面（或让 Kiwi 打开该文件的 `file://` 地址）确认安装

也可以先装 Tampermonkey，再 Import 这个 js。

### 使用

打开 `www.zhihu.com` → 菜单勾选「桌面版网站」→ 刷新。

右上角有状态角标 `✓ v0.7.0 393px ×2.49`，点击可暂停/恢复对比。不想要角标就把脚本顶部 `CONFIG.debug` 改成 `false`。

> **装完先看角标开头的版本号。** jsDelivr 的 `@main` 链接会缓存旧版（实测推 0.4.0 后拿到的还是 0.2.1/0.2.0）。拿到旧版就用带 commit SHA 的地址，或刷新 CDN 缓存。详见[安装说明](./安装说明.md)第七节。

### 自检

控制台执行：

```js
window.__zhihuFit()
```

健康状态下 `横向溢出` 应为 `0`。

## 可调参数

脚本顶部 `CONFIG`：

| 参数 | 默认 | 说明 |
|---|---|---|
| `debug` | `true` | 右上角状态角标，点击可暂停/恢复 |
| `fitHeader` | `true` | 顶栏超宽时自动裁剪导航项 |
| `hideSidebar` | `true` | 隐藏悬浮按钮、App 下载条 |
| `sideColumn` | `'hide'` | 右侧栏：`'hide'` 去掉（默认）/ `'bottom'` 移到正文下方 / `'keep'` 不动 |
| `hideRightRail` | `true` | 按**位置**兜底去侧栏：从正文反查祖先链，四条判据判定 |
| `fixFlexRows` | `true` | 修「多列 flex 把正文压成一条」（正文 24px → 345px）|
| `modalBackClose` | `true` | 弹层（「展开其他 N 条回复」等）：按返回键只关弹层、不退出页面 |
| `fixVUnits` | `true` | 修正 zoom 下失真的 `vw`/`vh` |
| `bodyFont` | `16` | 正文基准字号（px） |
| `sidePadding` | `12` | 页面左右留白 |

## 它做了什么

1. **抵消缩放** — `html { width: 393px; zoom: 980/393 }`
2. **拆掉硬编码 min-width** — 知乎顶栏 1175px、问题头部 1032px、主列 694px
3. **按实测宽度收拾 emotion 原子 CSS** — 知乎 84 张样式表、7208 条规则几乎全是哈希类名，选择器追不上改版，所以主力是扫描全量 DOM 处理显式 px 宽度、`flex-basis`、`flex-shrink:0`、负 margin
4. **修正 vw/vh** — zoom 下 `100vh` 会放大 2.49 倍，脚本把 `vh`/`vw` 改写成 `calc(N * var(--zf-vh))`
5. **去掉右侧栏** — 首页 / 问题页 / 专栏页通吃。结构启发式 + 从正文反查祖先链，都不依赖类名
6. **修 flex 行崩塌** — 多列 flex 容器会把正文压成一条竖线（实测 694px → 24px），检测到后让容器换行、内容块各占一行
7. **弹层返回关闭** — 评论里「展开其他 N 条回复」弹出的浮层，按手机返回键只关弹层、页面不动（URL 都不变）。浮层还会自动补一个 `✕ 关闭` 按钮

代码块、表格、轮播这类本来就该横向滑动的容器会打上 `data-zskip` 跳过压缩，保留原生手势。

## 已知限制

- **未做真机验证**，全部测试在 Playwright + Chromium 模拟环境完成
- 只测了问题页和发现页两个**真实**页面；个人主页、搜索结果页、评论区未覆盖
- **专栏页的崩塌修复是复刻页验证的**（真实页面被登录墙 + IP 风控拦截）。按真机 DOM 层级构造的复刻页上正文从 24px 恢复到 345px，**真机效果待确认**
- 右侧栏去除在复刻页 + 真实发现页/问题页上验证，**真实专栏页未覆盖**（同上，登录墙）。
  复刻页里侧栏全部用哈希类名（`css-r1r2r3`），不给任何 `SideColumn` / `aside`，逼脚本只能靠位置判断
- 弹层返回关闭在复刻页上验证。真实知乎的弹层实现细节可能有差异，脚本走的是「点关闭按钮 → ESC → 兜底移除」三级降级，最差也能关掉
- 知乎改版可能导致 `fitHeader()` 和 `hideSidebar` 的部分规则失效（主力扫描逻辑不受影响）

详见[制作与测试记录](./制作与测试记录.md)第 10 节。
