# v1.4.18 — 登录/注册页（SignFlowHomepage）单列化

日期：2026-10-23 ｜ 环境：MuMu 模拟器（小米 13 同参：1080×2400、DPI 440、CSS 视口 393×873）+ Kiwi(137) + 暴力猴 2.49.0，zhihu.com 开「桌面版网站」。

## 现象（用户反馈）

1. 「右侧的输入区域被截掉了」——登录卡片里的手机号输入框被屏幕右缘裁掉。
2. 首屏是一整屏插画，登录表单被推到第二屏之外。

## 根因（实测）

桌面版登录页 `.SignFlowHomepage` 是「左插画 + 右表单」的桌面双栏版式，落在窄列后三处叠加：

| # | 问题 | 实测数据（列宽 358） |
| --- | --- | --- |
| 1 | 背景插画：`.SignFlowHomepage` 挂 `background-image: sign_bg.png`，且自身被撑到 1925px 高、`.SignFlowHomepage-content` 是 `flex-direction: column + justify-content: center`（min-height 688px） | 插画占满首屏，LOGO 落在 y≈455，表单在第二屏之外 |
| 2 | 表单区 `.signQr-container` 是两列 flex：左 `.signQr-leftContainer`（「打开知乎App 扫一扫」二维码推广，162px）+ 右登录卡片（196px） | 卡片内输入行需要 ~310px ⇒ 右缘被裁（手机号输入框只露出左半） |
| 3 | 登录卡片外壳是 emotion hash（`css-10wc74s`），不能写进选择器 | 改用结构选择器 `.signQr-rightContainer > div` |

## 修法（全部稳定类名，只出现在登录/注册页）

```css
.SignFlowHomepage { background: none !important; min-height: auto !important; height: auto !important; }
.SignFlowHomepage-content { justify-content: flex-start !important; min-height: auto !important; }
.SignFlowHomepage-logo { display: block !important; margin: 24px auto 8px !important; }
.signQr-leftContainer { display: none !important; }
.signQr-container { display: block !important; }
.signQr-rightContainer, .signQr-rightContainer > div { width: 100% !important; }
.SignContainer-content { width: 100% !important; }
```

## 验证（2026-10-23，MuMu + Kiwi 137 + 暴力猴 2.49.0，--installed）

- `check-injected.js "zhihu.com/signin"`：`#z2m-style` 存在、78 条规则（v1.4.17 为 71 条，+7）。
- 验证码登录：手机号输入 `135..335`、短信验证码行 `25..335` —— 全部在屏内（此前输入框被 358 右缘裁掉）。
- 密码登录：两个输入 `25..335` 全宽；「其他方式登录」分隔行三段对称（左线 25..133 / 文字 149..211 / 右线 227..335）。
- 视觉：LOGO 顶部居中 (115..243)，卡片全宽 `1..359`，无插画、无推广面板。

## 取舍

- 「打开知乎App 扫一扫」二维码推广面板被隐藏：手机上扫码登录无意义，且它是把登录卡片挤到 196px 的直接原因。
- 插画背景整体去掉（而非缩小）：它是纯装饰，缩放后既占空间又无信息量。
- 未改表单内部任何控件（知乎自己的输入行排布在 358px 下工作正常）。
