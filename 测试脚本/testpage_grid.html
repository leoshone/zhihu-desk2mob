grid 布局变体：右侧栏列宽固定 296px

这个变体使用 CSS Grid 实现两栏布局，右侧栏列宽固定为 296px。在这种情况下，即使主列设置了 min-width: 0，grid 的 1fr 仍然会被压缩到很窄，因为列宽是硬性分配的。

继续填充正文内容，让主列的文本量明显大于侧栏。适配脚本需要能够识别这种 grid 两栏布局，并把 grid-template-columns 改成单列，让侧栏落到正文下方。
